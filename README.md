[![Build & Deploy](https://github.com/Anattasati/Anattasati.github.io/actions/workflows/pages.yml/badge.svg)](https://github.com/Anattasati/Anattasati.github.io/actions/workflows/pages.yml)
[![Security Audit](https://github.com/Anattasati/Anattasati.github.io/actions/workflows/security.yml/badge.svg)](https://github.com/Anattasati/Anattasati.github.io/actions/workflows/security.yml)

A contemplative publication about meditation, perception, and the nature of experience. The site is generated by Astro and deployed as static files to GitHub Pages.

## Test locally

You need Node.js 22.12 or newer.

```bash
npm install
npm run dev
```

Open <http://localhost:4321>. The development server updates as files change.

To test the exact production output:

```bash
npm run build
npm run preview
```

To run the full validation used in CI:

```bash
npm run ci
```

That command type-checks the Astro project, builds the static site, and verifies the expected routes, RSS feed, custom domain, and internal links.

## Project structure

```text
src/
├── components/         Reusable interface and luminous-field components
├── content/posts/      Markdown reflections and meditations
├── layouts/            Shared void and reading layouts
├── pages/              Routes, indexes, error page, and RSS endpoint
├── scripts/            Browser-side interaction code
└── styles/             Global visual system
public/                 Files copied directly into the production build
scripts/                Build verification
```

## Add a post

Create a Markdown file under either `src/content/posts/reflections/` or `src/content/posts/meditations/`:

```markdown
---
title: "My New Observation"
date: 2026-08-01T12:00:00-04:00
category: reflections
description: "A short summary for search results and link previews."
---

Your writing begins here.
```

The folder, `category`, and desired URL section should agree. The filename becomes the final URL slug, such as `/reflections/my-new-observation/`.

## Deployment

Pull requests run the production validation without publishing. A push to `main`, or a manually dispatched workflow on `main`, builds and deploys the site to GitHub Pages. The custom domain remains `anattasati.org` through `public/CNAME`.

In the repository settings, GitHub Pages must use **GitHub Actions** as its source.

## Design notes

The interface uses a restrained “Luminous Void” system: near-black index spaces, a warm reading surface, locally bundled variable fonts, and a single persistent canvas field that responds to pointer movement. Reduced-motion preferences receive a static version, and all content remains usable without JavaScript.
